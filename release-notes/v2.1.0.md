## Highlights

- **Claude Desktop per account.** Each account can open its own Claude Desktop window with its own login, side by side. Click the window button next to an account, or run `cswap desktop <name>`. The first time, the window opens on Claude's login screen; after that it stays logged in.
- Your existing Claude Desktop login shows up under the account it belongs to. MCP servers from your normal Desktop config carry over to the other windows.
- `cswap desktop` lists every account's Desktop window; `cswap desktop <name> --quit` closes one.
- **Tidier menu.** Plan labels are neutral, usage bars flat, and cached usage says how old it is ("Updated 2 hours ago"). Confirmations at the bottom clear themselves after a few seconds.
- Settings has a Claude Desktop section to hide the Desktop buttons.

## Fixes

- The shell integration loads again when `claude` or `cswap` was already defined as an alias in your shell startup file.
- `/swap` continues the conversation the session shows right now, also after `/clear` or `/resume`.
- An unreadable `.claude.json` is no longer replaced, which could log that account out.
- Ctrl-C cancels `cswap login` again.
- Closing Settings after opening it twice removes the Dock icon again.
- Launch at login shows the real error, and "waiting for approval" when macOS asks for it.
- A failed update check no longer hides an update that was already found.
- Setup from the menu bar writes to `$ZDOTDIR/.zshrc` when your zsh configuration lives there.
- Beta users get newer stable releases.

## Good to know

With more than one Claude Desktop window open, the Claude icon in the Dock only brings an open window to the front. Open accounts from CSwap.
